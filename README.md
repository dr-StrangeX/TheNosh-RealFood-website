THE NOSH — REAL FOOD RESTAURANT WEBSITE

A responsive restaurant website designed and developed for TheNosh, a Western restaurant based in Baisour, Lebanon.

LIVE DEMO
https://dr-strangex.github.io/TheNosh-RealFood-website/

TECHNOLOGIES
- HTML5
- CSS3
- JavaScript
- Git
- GitHub
- GitHub Pages

FEATURES
- Responsive desktop and mobile design
- Interactive navigation
- Menu category filtering
- Restaurant and food gallery
- Image lightbox
- Google Maps integration
- Click-to-call functionality
- WhatsApp reservation system
- Reservation availability handling
- Mobile navigation

PROJECT HIGHLIGHTS
- Designed and developed the website from scratch.
- Implemented the front-end structure, styling and JavaScript functionality.
- Optimized the layout for desktop and mobile devices.
- Integrated restaurant information, menu content, imagery and contact functionality.
- Version controlled the project using Git and GitHub.
- Deployed the website using GitHub Pages.

LOCAL DEVELOPMENT

1. Clone the repository.
2. Open the project folder in Visual Studio Code.
3. Open index.html with Live Server.

PROJECT STRUCTURE

index.html       Main website page
style.css        Website styling
script.js        Interactive functionality
images/          Website images
.gitignore       Git ignore configuration
