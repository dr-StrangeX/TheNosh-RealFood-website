THE NOSH — REAL FOOD WEBSITE
==============================

This version uses the restaurant photos and menu-board photos supplied by the owner.

Included:
- index.html
- style.css
- script.js
- images/ (restaurant + food photos)
- README.txt

Restaurant details used:
- Name: TheNosh
- Type: Western restaurant
- Rating: 5.0
- Location: Baisour
- Phone: 76 054 688
- Tuesday–Sunday: 2–11 PM
- Monday: Closed
- Target domain: https://thenoshrealfood.com/

FUNCTIONS
---------
- Responsive layout
- Menu category filtering
- Real menu items/prices transcribed from the supplied menu photos
- Menu-board image viewer
- Restaurant/food gallery with lightbox
- Google Maps directions
- Click-to-call phone links
- Reservation form that opens WhatsApp with a pre-filled reservation message
- Monday reservation blocking
- Mobile navigation

RUN IN VS CODE
--------------
1. Extract the ZIP.
2. Open the extracted folder in VS Code.
3. Install/use Live Server.
4. Right-click index.html -> Open with Live Server.

BEFORE PRODUCTION
-----------------
1. Verify every menu name/price against the restaurant's current printed menu.
2. Replace the placeholder "Our Story" copy with the restaurant's actual story.
3. Confirm the exact street address/map pin if available; the supplied screenshot only showed "Baisour".
4. Confirm the WhatsApp number is correct before launch.
5. Point thenoshrealfood.com DNS to your hosting provider.
6. For a permanent reservation system, connect the form to a database/booking platform instead of relying only on WhatsApp.
